# Landing page — prótese dentária

Site estático com `index.html`, `styles.css`, `script.js` e `start.sh` na raiz.
As imagens e os ícones ficam em `assets/`.

## Iniciar

```bash
bash start.sh
```

Acesse `http://localhost:4174`.

## Publicar no GitHub Pages

Em **Settings → Pages**, use **Deploy from a branch**, selecione a branch
`main` e a pasta **/ (root)**. O endereço principal passa a servir o
`index.html` da raiz, com os recursos relativos em `assets/`.
